

# نظام إدارة بلاغات الكهرباء

## الوصف
نظام إدارة بلاغات الكهرباء هو تطبيق ويب يهدف إلى تسهيل عملية تلقي وإدارة البلاغات المتعلقة بالكهرباء. يتيح للمواطنين تقديم بلاغات عن مشاكل مثل انقطاع التيار الكهربائي أو مشكلات في العدادات أو أي خطر كهربائي. يتيح أيضًا للإداريين متابعة وحل هذه البلاغات من خلال لوحة تحكم مخصصة.

## المميزات
- واجهة مستخدم بسيطة وسهلة الاستخدام.
- نظام تسجيل دخول للإداريين.
- إدارة البلاغات (عرض، تعديل، وحل البلاغات).
- إمكانية رفع صور داعمة للبلاغات.
- عرض البلاغات في جدول مع تفاصيل (رقم البلاغ، اسم الشخص، نوع البلاغ، والحالة).
- تصنيف البلاغات حسب حالتها (قيد المراجعة، تم الحل، جاري الإصلاح، وغيرها).

## كيفية التشغيل
1. **Clone** هذا المشروع إلى جهازك:
   ```bash
   git clone https://github.com/username/repository-name.git

2. تثبيت المتطلبات (في حال كان لديك Backend):

إذا كنت تستخدم Python (Flask أو Django):

pip install -r requirements.txt

إذا كنت تستخدم Node.js:

npm install



3. تشغيل التطبيق:

إذا كنت تستخدم Flask:

python app.py

إذا كنت تستخدم Node.js:

npm start



4. افتح متصفحك وادخل إلى العنوان المحلي: http://localhost:5000 (أو حسب المنفذ المستخدم)



كيفية المساهمة

1. Fork هذا المشروع.


2. أنشئ فرعًا جديدًا:

git checkout -b feature-branch


3. قم بإجراء التعديلات المطلوبة.


4. قم بعمل Commit للتغييرات:

git commit -m "أضف وصف التعديل"


5. Push التغييرات إلى الفرع:

git push origin feature-branch


6. قم بفتح Pull Request لدمج التغييرات في المشروع الرئيسي.
